# SyncJam – shared music room (friends install NOTHING)

Everyone opens the link in a browser, searches songs, and the same track plays in sync for all.

## Deploy free (so even you install nothing)
1. Put this folder on GitHub.
2. render.com -> New -> Web Service -> connect repo.
3. Build command: `npm install`  Start command: `npm start`
4. Share the URL Render gives you. Add `?room=anything` for private rooms.

## Run locally (optional, needs Node.js)
npm install && npm start -> open http://localhost:3000
